The agent what we built

apps.json→ HTTP doc finder→ optional Exa search→ LLM extract (smoke-v4)→ quote verifier→ records.json
  1. HTTP doc discovery (hint URL plus same-site developer links, capped at eight pages)
  2. Composio Exa Instant backup (EXA_SEARCH, EXA_GET_CONTENTS_ACTION) when login wording is missing
  3. OpenRouter extraction with google/gemini-2.5-flash-lite
  4. Quote-based generic verifier and Composio catalog match
Where a human was needed

  • The 28-app evaluation sample was fixed before any extraction.
  • Paid runs over five apps required an explicit cost estimate and COST_OK=yes.
  • Access and buildability stay unknown on most of the 100-app Pass 2 run (83 and 87 rows respectively).

  • Agreement with Clay does not prove either Clay or the agent is factually correct.
